# AgroDoc · sitio web

Sitio estático de **AgroDoc — Campo & Jardín · Servicio Técnico** (reparación y mantenimiento de motoimplementos en Itaembé Guazú, Posadas, Misiones).

- `index.html` — página única: servicios, cómo trabajamos, service pre-temporada, consejos y contacto (WhatsApp 376 511-2222).
- `assets/css/styles.css` — estilos con la paleta y tipografía del manual de marca (Barlow / Barlow Condensed, Google Fonts).
- `assets/img/` — logo, isotipo (favicon), ilustración de máquinas e imagen para compartir (`og-image.jpg`, 1200×630).

Se publica con **GitHub Pages** desde la rama `main` (carpeta raíz) en **https://www.agrodoc.com.ar/** (archivo `CNAME`). No requiere compilación: se edita el HTML y se hace push.
